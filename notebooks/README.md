# The competition notebooks

The three notebooks submitted to the in-class Kaggle competition, kept as they
were run. They are not the code in `recsys/`: that is a rewrite, and the four
silent bugs `tests/test_bugs.py` pins are bugs these notebooks have.

They are here because the rewrite makes claims about what the original did, and
a reader should be able to check those claims against the original rather than
take them on trust.
